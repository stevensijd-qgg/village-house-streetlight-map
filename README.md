# 乡村路灯与闲置房屋测绘标注系统

暑期“三下乡”社会实践中，以 Claude 为主要开发助手制作的村级测绘标注网页。
它把闲置（可出租）房屋、出租状态、照片、道路、路灯和测量地块集中到一张
高德卫星图上，**双击 `index.html` 就能用，不用安装任何软件**，还能直接打印
A3 / A1 / A0 高清分布图交给村委。

> **关于示例数据**：仓库中的房屋、房主、电话、地址全部是**虚构示例数据**，由脚本
> 沿道路随机生成，不对应任何真实房屋或个人；仓库不包含任何入户照片、走访表格或
> 原始点位记录。道路与沿路路灯盏数来自实践中对村内公共道路的手绘与 GPS 记录。

## 快速开始

1. 下载或克隆本仓库。
2. 用 Chrome / Edge 双击打开 `04_网页程序/index.html`（离线可用，卫星底图需联网）。
3. 手机现场使用：把整个 `04_网页程序` 文件夹拷到手机，用手机浏览器直接打开
   `index.html`——**必须本地打开**，通过局域网 `http://IP` 打开时浏览器会禁止 GPS 定位。

局域网共享给同组人看：双击 `启动局域网共享.bat`（需要电脑装了 Python，仅此一处需要）。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 房屋查询 | 绿色房子=可出租，灰色+“已租”角标=已出租；点开看照片、房主、电话、面积、租金、附带农田/小院 |
| 照片浏览 | 按 `photos/编号/编号_序号.jpg` 自动识别，全屏查看、缩略图/键盘翻页 |
| 已出租标记 | 弹窗里一键标记/取消，统计栏同步，可一键隐藏已租 |
| 道路标注 | 手绘泥路/水泥路/柏油路，自动测长，粗细可调 |
| GPS 记录道路 | 拿手机沿路走一遍自动成线，WGS84 自动纠偏到 GCJ-02、抗噪过滤、防熄屏 |
| 修改道路形状 | 拖点、插点、延长、减短、一键“拟合修顺”（抽稀+圆滑），可逐步撤销 |
| 路灯 | 路灯是叠加在路面之上的属性（黄色虚线），可填每条路的盏数并统计 |
| 圈地测面积 | 逐点圈选，球面面积计算，显示平方米、亩、公顷；可导出/载入 JSON 备份 |
| 搜索与列表 | 按编号/房主/地址/备注搜房屋，按路名/类型搜道路 |
| 实时定位 | 蓝点 + 精度圈，现场找房用 |
| 打印出图 | 快速打印、18 级高清 A3/A1/A0、全村一张图 A0 1:5000 / A1 1:6000、A3×4 高清拼图 |
| 对外展示模式 | `publicMode: true` 时隐藏房主姓名电话；数据更新工具勾选后姓名电话不写入 `data.js` |

## 技术架构

- 单页原生 JavaScript + 本地 [Leaflet](https://leafletjs.com/)（`lib/`，离线可用），无构建步骤、无后端。
- 数据为同目录脚本文件：`data.js`（房屋/路灯，由 Excel 经“数据更新工具”生成）、
  `roads.js`（道路，由网页导出）。
- 道路、已租、面积、图标大小保存在浏览器 localStorage，按村名隔离；道路和面积可导出文件迁移。
- 道路文件、面积文件的导入只做 JSON 解析和严格校验，不执行文件中的脚本；导入失败自动回滚。
- 高清打印不截图：按纸张毫米尺寸和比例尺计算范围，直接铺 17/18 级卫星瓦片，
  房屋编号、道路、路灯和地块用 SVG/HTML 矢量重绘。
- 坐标统一使用 GCJ-02（高德）。手机 GPS / WGS84 数据必须纠偏，禁止直接混用百度 BD-09。

更多细节见 [项目说明.md](项目说明.md)。

## 换成你自己的村

1. 按 `02_闲置房屋信息汇总表.xlsx` 的表头填写走访数据（坐标用高德 GCJ-02）。
2. 打开 `04_网页程序/数据更新工具.html`，连同表头复制粘贴表格，填村名，生成并下载 `data.js`，
   覆盖 `04_网页程序/data.js`。GPS/WGS84 坐标请勾选“自动纠偏”。
3. 照片放到 `04_网页程序/photos/编号/编号_1.jpg`、`编号_2.jpg`……（序号连续、小写 `.jpg`）。
4. 在网页里手绘或 GPS 记录道路，点【导出道路文件】得到新的 `roads.js`。

## 运行测试

需要 Node.js 18+；浏览器测试需要 Windows 上的 Microsoft Edge。

```bash
cd 04_网页程序
node --test --test-concurrency=1 tests/*.test.cjs
```

浏览器测试会以临时 profile 启动无界面 Edge，结束后自动关闭并清理，不影响日常浏览器。

## 隐私提示

房主姓名、电话和入户照片属于个人信息。实际部署时请勿把真实 `data.js`、`photos/`、
走访表格公开发布；对外展示请使用 `publicMode: true` 并用数据更新工具的“对外展示模式”
重新生成 `data.js`。

## 精度声明

房屋和 GPS 点位精度约 5～15 米，距离和面积为村级调查估算，不具备法定测绘精度。
卫星影像与路网注记来自高德地图在线瓦片，使用时请遵守其服务条款。
