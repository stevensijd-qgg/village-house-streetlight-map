================================================
乡村路灯与闲置房屋查询网页程序 —— 使用说明
================================================

【打开方式】
直接双击 index.html，用浏览器打开即可。
不需要安装任何软件，不需要服务器。
浏览器不限：Edge、Chrome、360、QQ浏览器、手机自带浏览器、
微信内打开都可以（Windows自带的Edge就很好，无需另装谷歌）。

【局域网共享（让同WiFi下的手机/电脑都能看）】
1. 双击本文件夹里的"启动局域网共享.bat"；
2. 首次启动如弹出Windows防火墙提示，勾选"专用网络"点【允许访问】；
3. 窗口里会显示一个 http://本机IP:8000 的地址，
   其他人连接同一个WiFi后用浏览器打开该地址即可；
4. 共享期间保持该窗口开着，关掉窗口就停止共享。
（前提：本机装有Python。你这台电脑已装好，直接用。）

【联网说明（重要）】
只需要普通的大陆网络（宽带/手机流量都行），不需要任何
翻墙/外网：卫星底图来自高德的国内服务器，村里能刷手机
地图就能用。点位数据和照片存在本地，完全断网时地图底图
不显示，但左侧列表和房屋详情仍可查看。

【当前数据】
已载入何桥村 82 处房屋和 0 个独立路灯点位。
道路标准数据为 51 条道路，51 条有路灯，48 条填写正数，
沿路路灯合计 597 盏；3 条零值/未填数量按原样保留。

【文件夹结构】
  index.html         主程序，双击打开
  data.js            点位数据（房屋+独立路灯点位）
  road-data.js       道路文件安全解析与规范化模块（勿动、勿漏）
  area-data.js       面积地块JSON备份模块（勿动、勿漏）
  roads.js           项目默认道路（含沿路路灯标记和盏数）
  数据更新工具.html   把Excel数据转成 data.js 的小工具
  photos\            房屋照片文件夹
  lib\               地图程序库（勿动）
  使用说明.txt       本文件

【怎么换成你们村的真实数据？】（2分钟）
1. 先把《02_闲置房屋信息汇总表.xlsx》填好；
2. 双击打开"数据更新工具.html"，按页面上的步骤操作：
   从Excel复制→粘贴→生成→下载 data.js；
3. 把下载的 data.js 复制到本文件夹，覆盖旧文件；
4. 把房屋照片放进 photos 文件夹：推荐每处房屋建一个
   以编号命名的子文件夹（如 photos\GH001\），里面照片按
   "编号_序号.jpg"命名（GH001_1.jpg、GH001_2.jpg，序号从1
   连续编，小写.jpg）；直接放 photos 根目录也可以——
   按规则命名的照片网页会自动全部识别，Excel里
   "照片文件名"列不填也行（详见 photos\照片命名说明.txt）；
5. 刷新 index.html 即可。

【功能说明】
- 图标含义：绿色房子=可出租闲置房屋；
  灰色房子+"已租"角标=已出租房屋；
  黄色圆点=完好路灯，灰色圆点=损坏/待修路灯
- 左上角"☰ 列表"按钮：收起/展开左侧定位列表
  （手机上默认收起先看地图；点列表里的房屋定位后、
  或点一下地图空白处，列表都会自动收起）
- 左侧列表：上半部分是出租房屋，下半部分是已画的道路
  （显示路名、类型、长度、路灯盏数）；点击任意一项，
  地图自动定位并弹出详情，点道路会缩放到整条路
- 顶部搜索框：房屋按编号、房主姓名、地址、备注搜索；
  道路按路名、类型（如输"路灯线""水泥路"）搜索
- 顶部勾选框：控制显示/隐藏 房屋、路灯、道路 三类标注
- 顶部"图标大小"滑块：拖动即可放大/缩小地图上的房子图标
  （12~40 档，网页会记住你的选择）
- 顶部【📍 定位】按钮：在地图上显示自己的实时位置蓝点
  （现场跑路时用，需手机本地打开网页，详见【GPS实地记录道路】）
- 点击地图上绿色房子：弹出状态、照片、房主、电话、
  面积、租金、附带农田/小院等详情，照片可用‹›翻页
- 再点击弹窗里的照片：全屏显示该房屋的所有照片，
  下方有全部缩略图可点选，‹›或键盘左右键翻页，
  点×、按Esc或点暗处关闭

【已出租标记】（房屋租出去之后用）
1. 点开该房屋的弹窗，点底部的【标记为已出租】按钮；
2. 该房屋立刻变成灰色房子+"已租"角标，顶部统计
   同步显示"已租 N"；点错了再点一次【取消已出租标记】
   即可恢复；
3. 想暂时不看已租出去的房屋：勾选顶部的"隐藏已出租"，
   地图和左侧列表里都会隐藏它们，取消勾选就恢复显示。
注意：标记记录保存在"本台设备的这个浏览器"里，换一台
电脑/手机或清除浏览器缓存后标记会消失，多人各自标记
互不同步。正式的出租情况建议同时记到Excel汇总表备注列；
如果希望标记"写死"进数据里所有人都能看到，把已租的
编号告诉制作者，在 data.js 该房屋里加一行 "rented": true
即可（网页里仍可临时取消）。

【道路标注】（手绘泥路/水泥路/柏油路，自动算长度）
点顶部【✏ 道路】按钮展开工具条：
1. 选路面类型（泥路=橙色虚线、水泥路=蓝色实线、柏油路=深灰实线）；
   这段路要是装了路灯，再勾上"这段装了路灯（叠加黄线）"——
   画出来就是路面色 + 亮黄虚线两种颜色（既是柏油又有路灯一眼看出）；
   拖"画笔粗细"滑块选粗细，点【🖊 开始画路】；
   （下拉里还留着"路灯线"这个老类型，是给以前画的路用的，
   新画的路建议用"路面类型 + 勾路灯"的组合）
2. 沿着道路在地图上一下一下点（鼠标会变十字线），弯道多点几个
   点就圆滑；卫星图上看不见的路照样画——你点哪里路就画到哪里；
   点错了按【撤销上一点】；
3. 点【✓ 画完了】（或双击地图），程序自动算出这条路的长度，
   并弹出编辑框，可以顺手给路起个名字（如"村部到高冲组主路"）；
4. 以后点地图上任何一条路：能看长度、改路面类型、勾/去掉路灯、
   填路灯盏数、改粗细（拖滑块立即变粗变细）、改名字、删除；
5. 【有没有路灯】三个地方都能改，改哪个都一样：
   画路工具条的勾选框（画之前选）、道路弹窗里的勾选框、
   左侧道路列表每条右边的💡按钮（点一下就切换，黄的=有路灯）。
   要给一批老路补上路灯属性，在左侧列表里挨个点💡最快；
6. 【路灯盏数】这条路上有几盏就在弹窗里填几，地图上会在这条路的
   中间位置显示黄色标签"💡 N 盏"（填 0 则不显示）；标签大小跟着
   顶部"图标大小"滑块一起变，打印大图时想让盏数更醒目就拖大它；
   填了盏数（大于 0）会自动勾上"有路灯"；反过来取消"有路灯"时，
   会先询问，确认后盏数清零（有盏数就一定算有路灯，两者始终一致）；
7. 顶部统计栏自动汇总：各类路面总长、装了路灯的路段总长
   （"亮化路段"）、路灯总盏数；打印时（快速打印和高清工程图都算）
   道路双色、路灯盏数标签和图例会一起印上。
长度说明：按你点的折线沿线计算，18级卫星图上描的线误差一般
只有百分之几，村级上报完全够用。
注意：道路及其路灯标记和盏数既保存在当前村浏览器工作副本中，也会进入
【💾 导出道路文件】下载的文件。下载后浏览器可能自动命名为 `roads (1).js`，
不用先改名，直接点【📂 选择道路文件】选择它即可。程序会显示道路数、
有路灯路段数和总盏数；确认后才覆盖当前村道路。覆盖前先【导出道路文件】备份；
取消或文件错误不会改现有数据。只有维护人员需要把文件作为项目默认道路时，
才把它改名为 `roads.js` 并放到 index.html 同级。

【一次性迁移到本次标准道路】
1. 打开网页，先点【💾 导出道路文件】保存当前浏览器道路备份；
2. 点【📂 选择道路文件】，选择项目同级的 `roads.js`；
3. 在确认摘要中核对：51 条道路、51 条有路灯、597 盏，再确认覆盖。
数据更新工具生成 data.js 时，村名必须填写“何桥村”；村名空着会阻止生成。

【修改道路形状】（画错了/GPS轨迹歪了，不用删了重画）
任何已有的路都能改——手绘的、GPS走出来的、别人发来 roads.js
载入的都一样：
1. 点地图上那条路 → 弹窗里点【✎ 修改形状】，路上每个坐标点
   都变成小圆点（两头是方形橙点），工具条切成"正在修改"，
   实时显示长度和点数；
2. 【挪点】直接拖任何一个点到正确位置；
3. 【延长】点选一头的方形端点（选中变黄），然后在地图上
   一下一下点，路就从那头接着往外长；
4. 【减短】点选要去掉的点，点【🗑 删除选中点】；删的是端点时
   会自动选中新端点，连着点删除就一截截缩短；
5. 【加点】直接点道路线上任意位置，就在那里插一个新点
   （弯道不够圆滑时用）；
6. 【✨ 拟合修顺】一键修顺：先自动删掉GPS抖动产生的多余点
   （偏离不到2.5米的都去掉），再把折角削圆。GPS录的路点太多、
   歪歪扭扭时点一下立竿见影；嫌不够顺可以再点一次；
7. 改错了点【↩ 撤销】（一步步退回）；满意了点【✓ 保存修改】；
   整个不想要这次改动点【✗ 取消】，路恢复进来时的原样。
修改和画路一样存在本机浏览器里，要带走记得【💾 导出道路文件】。

【圈地测面积】（在卫星图上手动框选地块，自动算面积）
1. 点顶部【📐 测面积】展开绿色工具条，可先填写地块名称并选择边线颜色；
2. 点【✚ 开始圈地】，沿着农田、宅基地、小院等边界依次点击；
   已点 3 个点后会出现半透明地块，工具条实时显示当前面积；
3. 点【✓ 完成圈地】（或双击地图）自动闭合边界，地图中心显示面积标签；
   结果同时给出平方米、亩，超过 1 万平方米时还显示公顷；
4. 点已保存地块可查看完整面积并删除；工具条【清空全部地块】可一次清除；
5. 顶部“地块”勾选框控制显示/隐藏，普通打印和高清工程图都会带上
   地块边界、名称和面积标签；“图标大小”滑块也会调整面积标签字号。
6. 换电脑前点【💾 导出地块文件】，保存“何桥村-面积地块.json”；
7. 新电脑点【📂 选择地块文件】，核对村名、地块数和总面积后确认整体覆盖。
注意：测量地块仍自动保存在本机浏览器，网页不会自动读取同级面积文件；只复制文件夹
不会带走浏览器地块。面积按球面坐标计算，精度主要取决于边界点是否点准，适合村级调查和估算。

【GPS实地记录道路】（拿手机沿路走一遍，自动画路测长）
去村里跑路时用这个，不用手描——人走到哪，路画到哪：

▶ 出发前：把程序装进手机（一次就好）
1. 电脑上把"04_网页程序"文件夹压缩成 zip
   （photos 照片文件夹太大，可以先移出去再压，现场用不到照片）；
2. 微信发到手机 → 手机上解压（微信里长按文件→用其他应用打开→
   解压工具，或先保存再用手机自带"文件管理"解压）；
3. 解压后找到 index.html，用手机的 Chrome / Edge / 自带浏览器
   打开（长按或点开时选"浏览器打开"）。
   ⚠ 两个"不行"：不要在微信里直接点开网页（微信内置浏览器
   不给定位）；也不要用局域网 http://IP 地址打开（浏览器出于
   安全会禁止定位）。必须是手机本地打开的才能用GPS。

▶ 现场：一条路一条路地录
1. 到路口，点顶部【📍 定位】，浏览器询问时点【允许】，
   地图上出现蓝点（周围淡蓝圈是精度范围，圈越小越准）；
   在开阔处等几秒，蓝点稳定了再开始；
2. 点【✏ 道路】展开工具条，选好类型（泥路/水泥路/柏油路），
   点【🛰 开始GPS记录】；
3. 拿着手机沿路正常走，工具条上实时显示已走长度和GPS精度，
   地图会自动跟着你移动；期间保持屏幕亮着（网页会自动防熄屏，
   保险起见把手机的自动锁屏时间调长些），别切到别的软件；
4. 走到路尽头，点【✓ 结束保存】→ 弹出编辑框，确认类型、
   顺手起个名字；录错了点【✗ 放弃记录】重来；
5. 下一条路重复 2~4。一天跑完所有路，长度自动都算好了。

▶ 回来后：把手机上录的路合并回电脑
手机网页上点【💾 导出道路文件】→ 下载道路文件 → 微信发回电脑。
电脑打开网页后，不必先改名或放进网页同级：点【📂 选择道路文件】直接选择
任意文件名的道路文件 → 核对道路数、有路灯路段数和总盏数摘要 → 确认覆盖当前村道路。
如果电脑浏览器里以前也画过路，先【💾 导出道路文件】备份；取消或文件错误不会改旧版本。
只有维护人员要把文件设为项目默认道路时，才改名为 `roads.js` 放在 index.html 同级。

精度说明：手机GPS误差一般5~15米，路的长度村级上报完全够用；
信号弱的点（树荫、屋檐下）程序会自动丢弃，显示"信号弱"时
原地等几秒即可。建议正式开录前先短走一段试录一次，确认
蓝点和轨迹正常。多台安卓手机可以分头录，各自导出 roads.js
后发给制作者合并。带个充电宝，屏幕常亮比较耗电。

【怎么打印地图】（打印带"已租"标记的纸质图）
点顶部【🖨 打印】按钮会弹出菜单，有三类打法：

▶ 快速打印（当前画面，适合 A4/A3 日常用）
1. 标好"已租"；要连已租的一起打就不勾"隐藏已出租"，
   只打可出租的就勾上它；
2. 缩放、拖动地图把要打的范围框进画面，尽量放大
   （放得越大越清晰）；
3. 点菜单第一项，约1秒后弹出打印窗口：纸张A4/A3、
   方向【横向】、勾选【背景图形】、边距默认，打印即可；
   打印完页面自动恢复。

▶ 高清工程图 A3 / A1 / A0（正式大图纸用这个）
原理：程序自动用最高清晰度（18级，约0.6米/像素）的
卫星底图铺满整张图纸，编号、标题、图例、比例尺、
指北针都是矢量绘制，多大的纸都锐利；页面尺寸就是
真实的 A1/A0 毫米数。
1. 标好"已租"，把村子中心拖到画面中间
   （不用管缩放级别，程序按图纸大小自动取范围：
   A3约宽0.9公里、A1约1.8公里、A0约2.6公里，比例尺约1:2200）；
2. 点菜单里的【高清工程图 A1】（或A0/A3）；
3. 屏幕中央显示"正在加载高清底图 x/y"，等它跑完
   自动弹出打印窗口（第一次约1~3分钟，之后很快；
   等不了可点提示条取消）；
4. 打印窗口里：目标打印机选【另存为PDF】→保存，
   得到的 PDF 就是真正 A1/A0 尺寸的工程图文件，
   U盘/微信发给打印店，说"按原尺寸打印，不要缩放"；
   （若电脑直连了大幅面绘图仪，也可直接选它打印）
   缩放选"默认/100%"，勾选【背景图形】；
5. 出 A0 建议用电脑操作，手机内存可能不够。

▶ ★ 全村一张图 A0（1:5000）／A1（1:6000）——要"整个村装进一张纸"用这个
上面那三档是按当前画面取景的，比例尺固定约1:2200，
A0 也只盖 2.6×1.8 公里，而何桥村东西 3.7 公里、南北 3.0 公里，
一张打不下（得拼 4 张）。这两档专门解决这个问题：
· 瓦片降到 17 级、纸面缩得更小，换来更大的覆盖范围；
· 【A0 1:5000】覆盖 5.9×4.2 公里，和村委那张遥感影像图同比例尺；
· 【A1 1:6000】覆盖 5.0×3.5 公里，绘图仪只有 A1 时用；
· 不用先拖画面——程序自动按"全部房屋点＋全部道路"的外接矩形居中，
  实测 82 处房屋、51 条道路全部落在纸内，一张打完；
· 底图分辨率约 1 米/像素（不是 0.6 米），大图远看无差别，
  凑到 30 厘米内看卫星影像会比 1:2200 那档略糊，属正常；
· 瓦片数约 780 张，比 A0 那档多一点，加载慢些，耐心等进度条。
其余步骤（另存为PDF、按原尺寸打印）与上面完全一样。

▶ ★ 何桥村 A3 × 4 高清拼图——普通 A3 打印机分四张打完整村
这档专门按“尽量只用 4 张 A3，同时要高清”设计：

· 自动按全部房屋、道路、路灯和测量地块取景，并在四周留 15% 安全边界；

【对外展示脱敏（重要）】
给村委内部用：data.js 里 publicMode: false（默认，显示姓名电话）
对外展示/上大屏：用记事本打开 data.js，把 publicMode: false
改成 true，保存后刷新网页，姓名和电话就会隐藏，也不能再按房主姓名搜索。
注意：手改 publicMode 只是网页上不显示，姓名电话仍在 data.js 文件里，
懂电脑的人打开文件就能看到。真正要把网页拷给外人，请用"数据更新工具"
勾选"对外展示模式"重新生成 data.js——这样姓名和电话根本不会写进文件。

【常见问题】
Q: 地图空白？          → 检查电脑是否联网（底图需在线加载）
Q: 照片显示"未找到"？  → 照片没放进photos文件夹，或文件名
                          和Excel里写的不一致（注意大小写和.jpg）
Q: 点位位置不对？      → 确认Excel里经纬度是高德（第四记高德
                          底图）坐标，且经度纬度两列没填反
Q: 所有点整体朝同一方向偏了几百米？
                        → 坐标是GPS/WGS84的（不是高德坐标）。
                          用"数据更新工具"重新生成时勾选
                          "经纬度是GPS/WGS84坐标，自动纠偏到高德"即可
Q: 新数据没生效？      → 确认下载的data.js已覆盖旧文件，
                          浏览器按 Ctrl+F5 强制刷新
